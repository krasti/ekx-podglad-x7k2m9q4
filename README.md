# EKSLUZYWNY.com — podgląd serwisu

Jednoplikowy, klikalny podgląd serwisu redakcyjnego EKSLUZYWNY.com (magazyn dobrego stylu).

**Podgląd na żywo:** po włączeniu GitHub Pages → https://krasti.github.io/eksluzywnycom/

Zawartość: strona główna / kategoria / artykuł, przełącznik Desktop 1440 / Mobile 390, wyszukiwarka (4 stany), menu mobilne i megamenu. Zdjęcia to placeholdery (picsum.photos) — wymagają internetu.

## Jak włączyć GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save
3. Po 1–2 minutach strona działa pod adresem powyżej.

Wygenerowano z design systemu EKSLUZYWNY.COM (Claude Design), 1 września 2026.
